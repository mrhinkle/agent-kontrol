# Agent Kontrol logo files

- `agent-kontrol-wordmark-navy.svg` for light backgrounds, `agent-kontrol-wordmark-white.svg` for dark ones.
- `agent-kontrol-wordmark-byaie-navy.svg` and `agent-kontrol-wordmark-byaie-white.svg` add "BY THE AIE" under the name. Use these for the project's own README and announcements.
- `agent-kontrol-icon.svg` is the app icon (navy tile, white reticle, orange marker). `src/app/icon.svg` is the same file, used as the favicon.
- Colors: navy `#0b1f4b`, orange `#ff6d00`, white `#ffffff`.

The wordmark letters are outlines of Montserrat ExtraBold (Copyright The Montserrat Project Authors), used under the SIL Open Font License 1.1 (https://openfontlicense.org). The brand typeface is Montserrat ExtraBold.
