# Code of Conduct

## Purpose

This project works best when everyone can participate without friction. This code sets the baseline for that.

## Expected behavior

- Be respectful, patient and constructive.
- Assume good faith and give others the benefit of the doubt.
- Critique ideas and code, not people.
- Stay on topic and keep discussions useful to others.

## Unacceptable behavior

- Harassment, personal attacks, insults or discriminatory remarks.
- Publishing others' private information without consent.
- Sexualized language or imagery.
- Any conduct that would be unwelcome in a professional setting.

## Scope

This code applies in all project spaces: issues, pull requests, reviews, discussions, chat, and any forum where the project is represented.

## Enforcement

Maintainers enforce this code. They may remove content, reject contributions, or ban participants who violate it, taking context and severity into account.

## Reporting

Report problems through a private GitHub report to the maintainers, or by direct message to the maintainer on GitHub. Maintainers review reports and respond as they see fit.
