# Mission Control brand assets

The wordmark is Futura Bold, converted to outlines (no font dependency), with a
crosshair ring replacing the O in MISSION. The flame-orange vector (`#f44800`)
is the same in every variant.

| File | Use on |
| --- | --- |
| `mission-control-wordmark.svg` | Light backgrounds (navy `#0b1f4b`) |
| `mission-control-wordmark-dark.svg` | Dark backgrounds (paper `#f3f5fa`) |
| `mission-control-mark.svg` | Light backgrounds, icon only |
| `mission-control-mark-dark.svg` | Dark backgrounds, icon only |

All files have transparent backgrounds. The favicon is `src/app/icon.svg`; it
switches ring colour with `prefers-color-scheme`.

Below about 24 px, use the mark on its own rather than the wordmark. The ring
is deliberately thinner than the lettering, so keep clear space equal to the
ring's diameter on every side.
